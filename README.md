# 🎭 Mehfil – Event Booking Website

A responsive web platform for event booking and venue management. Mehfil allows users to browse services, explore galleries, send inquiries, and book events online, while providing a robust backend for data handling and communication.

## 📌 Features

- 🏠 Explore gallery, menu, and services pages
- 📩 Contact form with automatic form reset after submission
- 📆 Event booking form with confirmation email notifications
- 🔐 Backend validation and secure data storage
- 📊 Admin access to booking and inquiry data

## 💻 Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript, jQuery, AngularJS
- **Backend:** Python (Flask)
- **Database:** MySQL / SQL
- **Tools:** MySQL Workbench, VS Code

## 📸 Screens & Pages

- Home Page (`frontpage.html`)
- Gallery Page (`gallery.html`)
- Services Page (`services.html`)
- Menu Page (`menu.html`)
- Contact Page (`contact.html`)
- Booking Page (`booking.html`)
